# Helpers

Builders and reviewers here use helpers exactly as OpenWiz's `docs/agents/helpers.md` (in `openwizdev/OpenWiz`) described: how to start, brief, check and archive one. OpenWiz removed that page on 2026-11-20; its [last version](https://github.com/openwizdev/OpenWiz/blob/7cb6ea12b13d0ac8db080fe4a6ced3effe7652f5/docs/agents/helpers.md) is at commit `7cb6ea12`. Agent settings are in [fleet.md](fleet.md). A helper grants no merge, publishing, live or dependency permission.
